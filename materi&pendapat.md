

## 1. Rangkuman Materi Workshop

Workshop membahas penggunaan Artificial Intelligence (AI) untuk membantu proses pembuatan website atau aplikasi. Selain itu, peserta juga diperkenalkan dengan Git dan GitHub sebagai tools untuk mengelola perubahan dan perkembangan proyek.

Materi yang disampaikan mencakup beberapa konsep dasar, yaitu:
- **Repository:** Tempat menyimpan file dan seluruh riwayat proyek.
- **Commit:** Proses menyimpan catatan perubahan pada proyek.
- **Branch:** Cabang pengembangan yang memungkinkan pengerjaan fitur secara terpisah.
- **Pull Request:** Pengajuan perubahan agar dapat ditinjau dan digabungkan ke branch utama.

Beberapa perintah Git yang diperkenalkan selama workshop antara lain:
- `git init`
- `git add`
- `git commit`
- `git push`
- `git pull`

## 2. Poin-Poin Penting dan Pengetahuan Baru

Melalui workshop ini, saya mendapatkan beberapa pengetahuan baru, di antaranya:

1. Memahami perbedaan antara Git dan GitHub. Git digunakan untuk mencatat dan mengelola perubahan proyek, sedangkan GitHub merupakan platform online untuk menyimpan repository dan berkolaborasi dengan orang lain.
2. Mengetahui fungsi repository, commit, branch, dan pull request dalam pengelolaan proyek.
3. Mempelajari beberapa perintah dasar Git untuk mengelola dan mengunggah perubahan proyek.
4. Memahami bahwa AI dapat membantu proses pembuatan website atau aplikasi dengan menggunakan prompt yang jelas dan terarah.
